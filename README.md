# تطبيق سطح المكتب "وَتِيرَة" (Wateerah Desktop)
**منصة إدارة ومراقبة استهلاك الطاقة المنزلية والمؤسسية والاستدامة البيئية — نسخة سطح المكتب (Windows .exe & Web)**

تطبيق متكامل باللغة العربية بالكامل وباتجاه من اليمين إلى اليسار (`dir="rtl"`) ومصمم خصيصاً لشاشات الكمبيوتر العريضة (Widescreen Desktop Layout) وفق لغة تصميم **Apple macOS / Apple.com**.

---

## 🚀 كيفية التشغيل وبناء ملف التثبيت (.exe)

### 1. التشغيل الفوري كخادم ويب محلي:
التطبيق يعمل مباشرة على الخادم المحلي المدمج:
```bash
node server.js
```
أو عبر `agy-node`:
```powershell
& "$env:APPDATA\Antigravity\bin\agy-node.cmd" server.js
```
ثم افتح المتصفح على: `http://localhost:3000`

---

### 2. التشغيل كبرنامج سطح مكتب مستقل (Electron):
```bash
npm start
```
سيفتح التطبيق في نافذة مستقلة مع شريط عنوان مخصص بدون إطار (Frameless Window) وأزرار macOS المرورية الملونة.

---

### 3. بناء وتصدير حزمة التثبيت المستقلة للويندوز (`Wateerah.exe`):
قم بتشغيل أمر البناء عبر `electron-builder`:
```bash
npm run build
```
أو:
```bash
npx electron-builder --win nsis
```
سيتم إنشاء ملف التثبيت `Wateerah-Setup-2.4.0.exe` والنسخة المحمولة (Portable .exe) داخل مجلد `dist/`، ويعمل البرنامج بدون إنترنت وبدون أي تبعيات خارجية مع حفظ كافة البيانات والإعدادات في `localStorage`.

---

## 🌟 الميزات الرئيسية المنجزة

### 1. مبدّل المنشآت المتعدد (Multi-Profile Facility Switcher)
يوفر 4 منشآت افتراضية واقعية جاهزة للتبديل اللحظي بنقرة واحدة:
1. **شقة سكنية (Apartment):** استهلاك منخفض (~3,200 kWh/شهرياً)، شريحة أولى (0.18 ر.س).
2. **فيلا عائلية (Villa):** استهلاك مرتفع (~7,500 kWh/شهرياً)، تتجاوز الشريحة الأولى وتدخل في الشريحة الثانية (0.30 ر.س).
3. **مدرسة تعليمية (School):** استهلاك مؤسسي بجدول زمني (الأحد - الخميس، 7:00 ص - 2:00 م، 22 يوماً/شهرياً)، تعريفة تجارية موحدة (0.26 ر.س).
4. **مبنى تجاري / مكاتب (Commercial):** تشغيل يومي طويل، تكييف مركزي Chillers وغرفة خوادم مستمرة 24/7، تعريفة تجارية موحدة (0.26 ر.س).
- **زر "+ إضافة منشأة جديدة":** نافذة لإنشاء وتخصيص أي منشأة جديدة مع حفظها في التخزين المحلي.

### 2. محرك القراءات الحية العشوائية (Randomized Live Telemetry Engine)
- محرك محاكاة مستمر كل 1.5 ثانية (`setInterval`).
- **نقطة الارتكاز الديناميكية (Dynamic Base Load):** حساب مجموع قدرات الأجهزة المفعّلة حالياً بالواط (`W`).
- **التذبذب العشوائي المستمر (Continuous Drift):** انحراف عشوائي مستمر بين `-12%` و `+18%` يحاكي تغير سحب الأجهزة اللحظي الحقيقي.
- **أحداث القفزات ودورات الكمبروسر (Random Spikes):** باحتمالية 20% لكل نبضة، يتم توليد أحداث واقعية وإدراجها في سجل الأحداث الحية (Live Event Feed).
- **أزرار التحكم بالمحاكاة:**
  - إيقاف مؤقت / استئناف البث المباشر (Pause / Live).
  - تسريع الزمن (`1x` / `5x` / `10x`).
  - زر **"محاكاة ضغط ذروة عشوائي (Simulate Peak Surge)"** لإطلاق قفزة حمل مفاجئة فوراً.
- **المؤشرات الحية:**
  - عدّاد رقمي عملاق للواط اللحظي والكيلوواط.
  - مؤشر الجهد المتذبذب (`218V – 224V`) والتيار بالأمبير (`A`).
  - رسم بياني خطي متحرك (Scrolling Live Line Chart) لأحدث 30 قراءة.
  - عدّاد تكلفة لحظي يتصاعد بالهللات والريال السعودي أمام المستخدم.

### 3. محرك التعريفة السعودية والاستدامة البيئية
- **التعريفة المعتمدة لدى هيئة تنظيم المياه والكهرباء (WERA):**
  - سكني: الشريحة الأولى (`0.18 ر.س` حتى 6,000 kWh)، الشريحة الثانية (`0.30 ر.س`) + رسوم العداد + 15% ضريبة.
  - تجاري: تعريفة موحدة (`0.26 ر.س`) + 15% ضريبة.
- **حلقات أبل للنشاط البيئي (Apple Fitness Rings):**
  - الحلقة 1: كفاءة الطاقة وترشيد الاستهلاك.
  - الحلقة 2: خفض انبعاثات ثاني أكسيد الكربون ($\text{CO}_2$ بمعامل 0.65 كجم/kWh).
  - الحلقة 3: ما يعادله من **عدد الأشجار المزروعة** (1.75 كجم CO2 شهرياً لكل شجرة).
- **توصيات ذكية مخصصة** تتغير آلياً حسب نوع المنشأة وأعلى جهاز مستهلك للطاقة.

### 4. تقرير التدقيق الرسمي المعتمد (Official Audit Report)
- زر **"تصدير تقرير رسمي (PDF / طباعة)"**.
- تصميم رسمي عالي الاحترافية متوافق مع معايير المركز الوطني لكفاءة الطاقة ومبادرة السعودية الخضراء.
- يتضمن: بيانات المنشأة، جرد الأجهزة، تفصيل الفاتورة والضريبة، شهادة الأثر البيئي، وأختام الاعتماد الرقمية.
